# Security Policy

## Supported Versions

Currently, we provide security updates for the following versions of LOCKON Workspace:

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of LOCKON Workspace seriously. If you discover a security vulnerability, we would appreciate it if you could report it to us privately so we can fix it before it is exploited.

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, please send an email to the repository maintainer or open a private security advisory on GitHub if enabled.

When reporting a vulnerability, please include:
*   A description of the vulnerability.
*   Steps to reproduce the vulnerability.
*   Possible impact of the vulnerability.

We will try to acknowledge receipt of your vulnerability report as soon as possible and keep you updated on our progress towards a fix.
